BetterEnglish 私人英语口语教练 — 本地分析版

一、先了解这次改了什么
保留了首页、词汇本、复习训练、口语练习、学习报告。
沿用 betterEnglish_ 开头的 localStorage 键名及原词汇结构。
新增 server.py：只监听 127.0.0.1:8080，将文本发送至本机 127.0.0.1:11434 的 Ollama。
浏览器不再直连 Ollama，不需要修改跨域设置，也不要关闭浏览器安全功能。
不使用付费 API，不需要 API 密钥，ChatGPT Plus 不参与网站调用。
Python 服务只用标准库，无需 pip 安装依赖。Ollama 和本地模型需要另外准备。

二、先备份与确认电脑（首次操作）
1. 保留原来的项目文件夹和收到的原始 ZIP。
2. 解压新版本到一个新文件夹，先不要覆盖原文件。
3. 可双击 check-mac.command，查看当前 macOS、芯片、内存、Python 和 Ollama 状态。
   它不会安装或下载任何东西。如果 macOS 阻止打开，可在终端进入文件夹后输入 bash check-mac.command。
   不要关闭 macOS 或浏览器的安全保护；也可逐一在“关于本机”查看硬件，在 Ollama 应用中查看模型。
4. 原有学习记录在浏览器中，不在 ZIP 中。请继续使用原来的 Chrome 用户、原来的普通窗口、
   同一个 http://localhost:8080 地址，不要切换到 http://127.0.0.1:8080、file:// 或其他端口。
   这些地址虽都在本机，却有不同的浏览器存储空间。不要清除网站数据。
5. 新版口语页提供“备份学习数据”，可下载本浏览器的 betterEnglish_ 数据副本。
   备份不包含录音。请妥善保存文件；当前未提供自动导入，避免误覆盖旧数据。

三、准备 Ollama（检查后才需要安装/下载）
云端无法确认你的 Mac 配置；之前提到的 M1、16GB、macOS 14.6.1 仍需本机复核。
如果仍是该配置，建议先尝试 qwen3:4b：中文解释能力合适，4B 规模比大模型更适合16GB内存。
模型文件约2.5GB，运行占用约数GB，具体取决于上下文和版本；下载前建议至少留出6GB磁盘空间。
这是候选模型，尚未在你的 Mac 上实测质量和速度，不能保证每份回答都分析正确。

先看 check-mac.command 的结果：
- 如果 Ollama 已安装且 ollama list 已有 qwen3:4b，不需要重复下载。
- 未安装时，从官方 https://ollama.com/download/mac 下载并安装 Ollama，打开应用。
  安装前检查官网当前系统要求是否适合你实际的 macOS 版本。
- 已安装但没有模型：打开“终端”，只运行这一条命令：
  ollama pull qwen3:4b
  这会下载约2.5GB的本地模型，不产生 API 费用，但会使用网络和磁盘。
- 不选择带 cloud 的模型。本服务会拒绝名称带 cloud 或声明为远端的模型。
  默认仅使用 qwen3:4b。高级用户可通过 BETTER_ENGLISH_MODEL 指定其他已下载的本地模型，
  但需自行确认该模型支持 Ollama 的结构化输出和 think:false。

四、启动网站（每次使用）
1. 打开 Ollama 应用，让它保持运行。
2. 如果旧的 Python 网页服务正在运行，在它的终端按 Control+C 停止。
3. 在新版文件夹双击 start.command。
   如果没有执行权限或 macOS 阻止直接打开：打开终端，输入 cd 后加一个空格，
   把新版文件夹从 Finder 拖入终端，然后按回车；再输入：
   bash start.command
   也可以在此文件夹直接运行 python3 server.py。
4. 看到“BetterEnglish 已启动”后，用原来的 Chrome 打开 http://localhost:8080。
5. 如果提示8080被占用，先关掉旧服务再试。不要为了避开冲突改端口。
6. 在口语页先输入英文做文本分析，不需要先开麦克风。

五、第一次验证真正的 AI 分析
1. 输入：Yesterday I go to the park with my sister. We enjoyed the sunshine.
   等待自动分析，或点“分析当前文本”。首次加载模型可能较慢，服务最多等待180秒。
   检查：原文仍是 go；分析是否结合 yesterday 判断过去时；参考回答是否保留姐姐/妹妹与公园的信息。
2. 再输入完全不同的内容，例如：I want to learn cooking because I enjoy making meals for my family.
   检查建议是否围绕学做饭，而不是仍然推荐公园或周末表达。
3. 对正确的回答，模型可以没有错误条目；自然度和可选风格不能伪装成语法错误。
4. 编辑原文会立即使旧反馈失效并取消旧请求；模型忙时会自动等待；同一回答分析中按钮暂时禁用，避免重复请求。
5. 模型返回的原文片段必须真实出现在文本中，否则整份反馈会被拒绝并提示重试。
   这能拦截虚构引用，无法自动证明每条语言判断或例句都正确，请结合实际使用检查。
6. 推荐表达最多5条，可听示范、加入词汇本，已存在的表达不会覆盖或重复添加。
7. “保留本轮，重新回答”会先保存原文、反馈和任务，再清空输入供下一轮使用。
   录音播放器不会被此按钮清空。过往练习里可展开反馈，与新回答对照。
8. 收藏后去词汇本和复习训练查看，再刷新验证仍存在。

六、录音、转写与朗读
- 使用 Chrome，允许 localhost 的麦克风权限。点击开始、说英语、再点停止。
- 实时文字展示在转写框上方；停止后等待识别完成，再把完整内容填入可编辑原文。
- 录音期间暂时锁定原文编辑，防止识别完成时覆盖手工输入。
- 处理识别器重复事件、自动重启和末尾临时文字。整理超过3.5秒时保留最后文字，提示回听检查。
  浏览器本身未识别出来的内容无法凭空恢复；请务必回听检查末尾。
- 录音仍可回放；录音只存在本次页面内存，刷新或关闭页面后不会保存。
  历史保存的是文字与反馈，沿用旧版行为，不会自动把录音上传给模型。
- 浏览器 Web Speech 语音识别可能连接浏览器厂商的远端服务，不承诺离线。
  若不愿使用该识别服务，可直接手动输入文本，模型分析仍在本机完成。
- 本服务不把文本或录音发送给其他外部服务。模型只分析文字，不能判断发音、口音或给雅思评分。
- 朗读仅选择浏览器标记为本机的英语语音；没有则提示安装，不会切到远端语音。
  可在 macOS“系统设置→辅助功能→朗读内容→系统声音”添加英语语音。
  连续点击会先停止上一段；“停止朗读”可随时停止。

七、常见问题
“无法连接本机 Ollama”：打开 Ollama 应用，确认 check-mac.command 能列出模型，再重试。
“模型不可用”：检查 qwen3:4b 是否下载完整；若使用不同模型，先明确配置本地模型名。
“模型返回格式错误/不完整/引用不存在的片段”：结果不会冒充成功；点重新分析。
“上一份分析仍在结束”：取消浏览器请求不一定能让 Ollama 立即停止推理。新版会自动等待并继续，无需反复点击。整体等待上限约6分钟，包含上一轮结束和本轮分析。
“本地分析接口未启动”：不要再使用 python3 -m http.server 8080；改用 start.command。
“等待超时”：检查 Ollama，关闭占内存的软件，缩短回答后重试。不要期待硬件尚未实测的速度。
“基础规则”：必须主动点击“仅用基础规则”，只检查少量模式，不代表完整 AI 分析。
  基础规则不生成待收藏表达，避免拿未经完整修正的句子充当自然例句。
“识别失败”：页面会显示权限、无语音、网络或设备等具体原因，可继续回放并手动输入。
“保存失败”：原文不清空，也不会假装已加入。先备份，再检查浏览器隐私设置与可用存储空间。
“旧数据不见了”：先确认浏览器用户、普通/隐身窗口、协议、主机名和8080端口均与原来一致；不要重置数据。

八、关闭
在运行网站的终端按 Control+C，按提示回车退出。需要时再退出 Ollama 释放内存。
不会删除浏览器已保存的学习记录。
